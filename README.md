# SickHacker

「シックハッカー」

（概要・テーマ）
この作品は、2018年の日本ゲーム大賞に応募する為にUnityで開発したゲームです。
テーマは、「うつす」だった為、「ロボットが風邪をうつす」つまり「ロボットがハッキングする」というテーマで制作しました。

(開発時期・期間)
HAL東京3年生時の2018年4月～2018年6月(3ヶ月)

（開発ツール）
・ゲームエンジン：Unity(バージョン 2018.1.6f1) →(バージョン2019.1.4f1)へ更新しています。
・言語：C# 
・開発環境：Visual Studio2017 
・3D データ制作：Maya 
・2Dデータの一部はフリー素材を使用しています。
・BGM・SEはフリー素材を使用しています。 
・Unityの公式アセットPost Processing StackとStandard Assetsを使用しています。

（チームメンバー）
開発チーム（計７人）
・プログラマー４人（担当）
・プランナー１人
・デザイナー２人

（担当内容）
チームリーダーではないのですがメンバー全体の指示や管理などのディレクター業務とプログラマーの 2 つを兼任しました。
プログラムは主にあたり判定の内容・タイム・HP・各アイテム内容・シーン遷移・ステージ選択・効果音・ステージデザインなどです。

（ゲームシステム）
ステージのギミックやロボットをハッキングしていきゴール目指すパズルアクションゲームです。
・ゴール(赤いパネル)にたどり着くとゲームクリアーになります。
・体力がなくなるとゲームオーバーになります。
・時間切れになるとゲームオーバーになります。
・プレイヤーキャラクターがステージから落ちるとゲームオーバーになります。
・キラキラのエフェクトが出ている水色のカプセルを5つ取るとゴールへの壁が開きます。
・回転ノコギリに当たると体力を1つ失います。
・リペアツールを取ると体力が回復します。
・砂時計を取るとタイムを回復します。
・ジャンプマシーンをハッキングして乗っ取るとジャンプする事ができます。
・バレットマシーンをハッキングして乗っ取ると弾を発射する事ができ、回転ノコギリを破壊する事ができます。
・青いキューブをハッキングすると透明な壁が消えます。
・空から降ってくる鉄球に当たると体力を1つ失います。

(操作方法)
・W・A・S・Dでキャラクターの移動をします。
・Eキーを長押ししながらQキーを押すことでハッキングすることができます。
・スペースキーで各種ロボットのアクションが可能になります。
・ESCキーでゲームを終了します。

(起動方法)
「シックハッカー(ビルド)」というフォルダーを開いてください。
その中にある、「JapanGameAward.exe」というアプリケーションをダブルクリックしてください。
